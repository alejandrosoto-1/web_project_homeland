# Tripleten web_project_homeland
Nombre del Proyecto: Diseño Web Adaptativo Homeland

Es una pagina web con diseño responsivo, ajustable a diferentes resoluciones de pantallas, 
que despliega informacion basica acerca de los lugares de origen de algunos de los programadores que han hecho 
vida en Tripleten

Se utilizaron diversas tecnologias tales como HTML, CCS. Github.
